# inventory-agent-okf

Repositorio OKF para un agente de inventario que recibe fotos como medio de comunicación y organiza objetos en bundles (catálogos) por tipo. Este repositorio contiene SOLO instrucciones, especificaciones y descriptores; no incluye código ejecutable.

Estructura principal del repositorio:
- README.md (este archivo)
- spec/ (especificaciones y esquemas en formato de instrucciones)
- bundles/ (descriptores por catálogo)
- docs/ (flujos de trabajo y procesos)
- storage/ (recomendaciones de almacenamiento)

Propósito:
- Definir cómo debe formatearse la información adjunta a cada foto (acción requerida, metadatos, identificación de objeto).
- Definir la estructura de los bundles OKF para cada catálogo de objetos.
- Documentar el flujo de procesamiento (especialmente la acción "añadir") y las reglas mínimas de datos.

Mantén aquí instrucciones claras para desarrolladores e integradores sobre cómo implementar servicios que consuman estas especificaciones y cómo construir/actualizar los bundles.
